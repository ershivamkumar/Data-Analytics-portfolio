# 🏦 Securitisation Risk Arena

## 📊 Project Overview

This project focuses on analysing securitisation risk using assumed bank data covering auto loans, mortgages, and structured credit.

The project will use Microsoft Power BI to build interactive risk assessment dashboards and perform financial analysis using DAX.

## 🎯 Objectives

- Analyse loan portfolios and credit risk
- Calculate Expected Credit Loss (ECL)
- Develop IFRS 9 risk analysis
- Perform stress testing
- Build waterfall calculations
- Create investor reporting dashboards
- Develop an interactive Securitisation Risk Arena simulation

## 🛠️ Tools

- Microsoft Power BI
- DAX
- Excel / CSV
- Data Analytics
